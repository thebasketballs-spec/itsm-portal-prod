Features
Incident & Request management — create, track, assign, resolve, and close tickets with rich-text descriptions and file/image attachments.
Role-based access control (RBAC) — four roles (User / Support / Manager / Admin) with menus and actions gated per role.
Approval workflow — Requests can require an approver; a My Tasks (Approve) tab surfaces pending approvals (auto-shown for User/Support only when they have items to approve).
SLA tracking & escalation — automatic response/resolution due dates by priority (P1 4h / P2 8h / P3 24h), breach flags, and escalation checks that run continuously.
Auto-close — resolved tickets awaiting requester confirmation auto-close after 7 days.
Customer Satisfaction (CSAT) — post-close survey with results broken down by Incident, Request, and combined totals, plus per-support-staff performance.
Dashboard — summary badges, SLA metrics, and charts (tickets by status/type) with data labels.
Reports, Audit Log, Admin Dashboard — bulk actions, filtering, aging and resolution metrics, and a full audit trail (including logins, imports, and status changes).
Master Data & User Management — maintain systems, categories, modules, users, and approvers; import/export via Excel.
Excel / CSV export — one-click export on most views (Manager/Admin).
Email drafts — generates Outlook Web compose links for approver notifications and status updates (never auto-sends).
Theming — five distinct color themes plus dark mode, saved per user.
Responsive — works on desktop, tablet, and mobile.
